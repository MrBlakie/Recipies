# Add a recipe

Copy the template below into a new Markdown file in **docs/recipes/**. Use a short filename with hyphens, such as **creamy-garlic-chicken.md**.

In GitHub, open the repository and choose **Add file → Create new file**. Enter the full path, paste your recipe, then choose **Commit changes**. Publishing runs automatically after each change to the main branch.

## Recipe template

```markdown
---
tags:
  - Chicken
  - Family favourites
---

# Recipe name

A short description of the dish.

| Serves | Prep | Cook |
| --- | --- | --- |
| 5 | 15 minutes | 30 minutes |

## Ingredients

- Quantity and ingredient
- Quantity and ingredient

## Method

1. First step.
2. Next step.
3. Finish and serve.

## Notes

- Substitutions, family preferences or changes for next time.

## Source

Original recipe link or book, if applicable.
```

## Tags

Change the example tags to suit the recipe. Keep spelling consistent, such as **Chicken**, **Beef**, **Pasta**, **Quick dinners** and **Family favourites**. Recipes can have more than one tag.

## Edit a recipe

Use the pencil icon on its page, or open the Markdown file in GitHub and choose **Edit**. Commit your changes to update the site. Visitors can browse the public site; editing requires GitHub access to this repository.

## Share a recipe

Copy the recipe page URL. To print, use your browser’s Print command.
